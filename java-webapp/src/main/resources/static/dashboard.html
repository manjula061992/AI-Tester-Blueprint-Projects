🆘 Troubleshooting

                    
                    

                        

                            
❓ Cannot open localhost:8080

                            
Solution: Make sure Java Spring Boot server is running. Run mvn spring-boot:run in the java-webapp directory

                        


                        

                            
❓ Port 8080 already in use

                            
Solution: Edit application.properties and change server.port=9090

                        


                        

                            
❓ Cannot connect to API endpoints

                            
Solution: Verify server is running and check browser console for CORS errors

                        


                        

                            
❓ Testcases not generating

                            
Solution: Check browser console and ensure input is descriptive. Try: "Create testcases for app.vwo.com login page"

                        


                        

                            
❓ Export button not working

                            
Solution: Generate testcases first, then use the export button that appears
