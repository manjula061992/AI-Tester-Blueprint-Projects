## 🎯 Core Mission
Enable users to generate structured, production-ready testcases by providing code/requirements input through a chat UI. GitHub Copilot serves as the local LLM engine.

**Purpose:** User-provided context for testcase generation


## 🛡️ Behavioral Rules

### User Interaction
1. User enters input via chat UI (code, requirements, or specs)
2. System validates input format & language
3. GitHub Copilot LLM generates testcases using template
4. System returns structured output in chat
5. User can refine, regenerate, or export testcases

### System Behavior
- **Deterministic Output:** Template ensures consistent testcase structure
- **No Guessing:** If input is ambiguous, ask for clarification instead of inferring
- **Error Handling:** Return user-friendly errors, not stack traces
- **Rate Limiting:** Respect GitHub Copilot API quotas gracefully
- **Local-First:** Prefer local processing; minimize external calls

### Content Validation
- Accept code in multiple languages (Python, JS, Java, etc.)
- Support textual requirements & API specifications
- Reject malformed or empty inputs
- Warn on extremely large inputs (>10K lines)

## 🏗️ Architectural Invariants

### Layer 1: Architecture (SOPs)
- `/architecture/testcase_generation_sop.md` → Defines testcase generation workflow
- `/architecture/copilot_integration_sop.md` → GitHub Copilot connection & usage

### Layer 2: Navigation (Decision Making)
- Route user input to appropriate handler (code vs. requirements)
- Call GitHub Copilot API with formatted prompt
- Format & validate output before delivery

### Layer 3: Tools (Deterministic Scripts)
- `tools/input_validator.py` → Validate input format
- `tools/copilot_connector.py` → Handle API communication
- `tools/testcase_formatter.py` → Format output to schema
- `tools/template_engine.py` → Apply testcase templates

### Forbidden Operations
- ❌ Do NOT modify testcase structure outside of schema
- ❌ Do NOT call Copilot without proper error handling
- ❌ Do NOT expose API keys in logs or UI
- ❌ Do NOT skip validation of user input
